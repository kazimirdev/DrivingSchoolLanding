# Driving School Landing

Responsywna strona typu landing page dla szkoły nauki jazdy z układami dla różnych urządzeń (desktop, tablet, telefon) oraz z panelem administracyjnym do zarządzania treścią.

**Zobacz wersję angielską:** [README.md](README.md)

## Opis

Repozytorium zawiera frontend (statyczny) dla landing page szkoły nauki jazdy. Znajdziesz tutaj responsywne szablony i zasoby przystosowane do różnych rozmiarów ekranów. Projekt został ukończony wcześniej i zawiera zrzuty ekranu dla widoków desktop, tablet i mobile w katalogu `.github`.

Główne cechy
- Responsywne układy: Desktop / Tablet / Telefon
- Nowoczesny, przejrzysty design nastawiony na konwersję
- Formularz kontaktowy i widoczne CTA (wezwania do akcji)
- Panel administracyjny
